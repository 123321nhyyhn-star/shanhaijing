## 资料位置

- `decompiled/`：整个 JAR 的 CFR Java 还原代码，重点看 `com/github/alexthe666/alexsmobs/client/model/`、`render/` 和 `render/layer/`。
- `resources/`：原始非 class 资源，包括实体纹理、方块/物品模型、数据与模组元信息。
- [来源与计数](manifest.json)：原始 JAR hash、文件数量和解码范围。
- `analysis/model-catalog.json`、`renderer-catalog.json`、`texture-catalog.json`：模型、渲染器与 PNG 索引。
- `analysis/models/<ModelName>.json`：构造器骨骼、cube、UV、镜像、旋转、源码行和解析警告。
- [纹理对照](previews/texture-study-board.png)：八个核对样本的最近邻 atlas 放大图。
- `previews/<ModelName>-white.png`：八个样本的构造器白模视图。
- [实时打开的 Gorilla 斜视](previews/ModelGorilla-live-threequarter.png)、[正面](previews/ModelGorilla-live-front.png)、[侧面](previews/ModelGorilla-live-side.png)：本次 Blockbench 验证截图。
- `live/ModelGorilla.bbmodel`：为验证实时参考流程重建的独立模型，嵌入 `gorilla.png`；不含运行时动画、条件显示或渲染层。

## 建模前必须实时参考

[项目中的 skill](../../skills/alexsmobs-model-reference/SKILL.md) 要求每次建模前选择最接近目标物种的 Alex’s Mobs 模型，在 Blockbench 或可交互三维查看器中实时打开，检查视角、骨骼和 UV/纹理，再写出具体建模取舍。历史笔记、源码、缓存图片和离线白模无法代替本次打开。

项目 [AGENTS.md](../../AGENTS.md) 已加入此规则。skill 内提供解包/索引、白模预览、带纹理 `.bbmodel` 还原三种辅助脚本，并包含完整模型索引和具体样本研究。

在 Blockbench 5.2.2 中实际加载了 Gorilla 参考模型，核对了 10 个骨骼节点与 11 个 cube 的坐标、旋转、UV、镜像和 inflate，共 21 项数据匹配检查通过；实时查看了三个视角和 chest/rightArm UV。之后切回用户原狌狌项目。原项目仍有 42 个 cube、23 个骨骼和 4 个动画。本次没有修改目标生物模型。

大型解码数据、第三方反编译工具和重建模型已仅在该参考目录下设置 Git 忽略；精简 skill、说明和参考图可随项目维护。
