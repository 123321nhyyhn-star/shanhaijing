## 开发路线

### 0：确定体验与技术基线

用一句话描述玩家为什么会想玩；选定平台和主循环。
检查本地 JDK、开发工具和游戏环境，根据确定的需求选择版本与加载器。
验收：明确第一版内容、暂缓内容、技术基线。

### 1：建立可运行工程

采用对应加载器的官方模板，设置模组标识与资源目录。
先加入一个最小物品或方块，验证注册、配方、中文名称与资源加载。
验收：能够构建 JAR，并在开发客户端中加载和使用。

### 2：完成第一条玩法闭环

实现一个代表性内容，让玩家能够从遇见内容一路玩到获得回报。
如果采用异兽路线，包含遭遇方式、核心行为、互动或战斗、奖励和引导。
允许使用临时模型与贴图，但完成条件必须可实际验证。
验收：生存模式中可以完整体验主循环，并正确保存进度。

### 3：扩展与打磨

根据试玩反馈扩展内容、改善动作和视觉表现、调整生成与收益。
逐项验证多人同步、专用服务器、存档重载与配置。
验收：可安装的版本、安装说明、已知问题和更新记录。

## 技术候选

如果选择 Java 版内容模组，可评估 Minecraft 1.21.1 + NeoForge + JDK 21。
这是候选基线，最终决定依赖玩法、已有环境和所需依赖的支持情况。
第一版只支持一个加载器与一个游戏版本。
优先让配方、掉落和生成参数能通过数据资源调整，先验证玩法再抽象框架。

官方参考：https://docs.neoforged.net/docs/1.21.1/gettingstarted/
