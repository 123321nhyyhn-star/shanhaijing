# 山海经模组：内容构筑草案

日期：2026-10-08。状态：讨论稿；所有玩法、装备名和技术方案均可调整。
本阶段先构筑想法，不把候选清单直接当成开发任务。

## 本轮已确认的方向

- 世界同时容纳自成生态的神话生物，以及具有禁忌感的稀有存在；两者可以重叠。
- 玩法以体系在世界中的构建为中心。
- 主设计链路为：场景 → 生物 → 禁忌 → 物品。
- AI、美术等作为配套路线并行推进，围绕相同场景与交互约定接入。
- 美术方案需要让用户无需亲自建模；现阶段应优先验证质量与制作流程。

## 场景如何组织体系

每个场景先确定环境、资源分布、普通生态、可见线索与玩家进入方式。
生物有各自的活动目的和生态关系；稀有存在可以影响局部生态、时段或区域规则。
禁忌设计记录触发条件、提前线索、后果、应对和恢复方式，注明原著依据与原创部分。
物品根据场景中的实际需求产生用途，也允许从一个区域带往另一个区域发挥作用。
这是需求与设计的顺序；实现可以在临时场景和占位资产上并行，试玩后回头调整。
稀有度、生态参与程度与规则影响范围分别设计，不按强弱排成固定等级。

每个场景的讨论稿包含：

1. 玩家来到这里首先看见和听见什么。
2. 常见生物如何生活、互动和利用资源。
3. 稀有存在出现时，哪些现象改变。
4. 玩家如何获得关于禁忌的线索。
5. 玩家可选择的行动、对应后果和有用物品。
6. 场景如何恢复，以及多人和重复进入时如何表现。

## 并行路线与共同约定

| 路线 | 当前需要产出的内容 | 与其他路线连接的约定 |
| --- | --- | --- |
| 原著与世界设计 | 来源卡、场景规则、生态关系 | 来源、原创标记、场景与生物标识 |
| AI | 可观察行为、感知与状态转换 | 状态名称、动作事件、攻击前兆和生效时机 |
| 美术 | 概念、模型、贴图、骨架、动作 | 尺寸、朝向、骨骼名称、动作名称与时长 |
| 场景与事件 | 地形、结构、栖息地、局部异常 | 空间范围、生成条件、触发与恢复规则 |
| 物品与成长 | 应对工具、资源用途和跨场景联系 | 获取途径、效果条件、消耗与收益 |
| 集成与试玩 | 将上述内容放入可体验场景 | 行为、画面、提示和实际结果一致 |

每轮围绕一个完整场景推进；临时模型与最终模型保持同一动作约定。
并行制作采用分文件分工，避免多个执行者同时修改同一模型或同一核心类。
具体是否使用多个代理，待实际实现任务分解后决定。

## 共同构思的方法

每个想法记录：原著依据、玩家体验、可观察线索、可采取的行动、获得的回报、代价与待解决问题。
区分三类资料：原著正文、古代注释与后世传说、模组原创改编。
目前使用维基文库的原文转录作初步查阅，其中夹有注释；正式内容选定后再核对版本、异文与解释。
造型先从正文的形态与声音出发，再设计方块风格的轮廓、动作和材质。

## 内容支柱候选

- 异兽生态：觅食、休息、领地、迁移、繁衍或独特使命。
- 探索与知识：声响、足迹、巢穴、遗留物与逐步补全的图鉴。
- 装备与工具：帮助玩家观察、应对和利用特殊现象。
- 奇花异木与矿物：让探索获得的资源进入食物、工具、建筑和祭仪。
- 神话事件：异兽出没与异常环境的关联，提供提前预警和应对办法。
- 玩家表达：营地、陈列、园圃、栖息地、路线标记与建筑材料。

## 原著与生物候选

### 狌狌：山林里的第一次相遇

- 原著：《南山经》招摇之山，形似禺、白耳，有伏行与人立行走的描述；正文提到食用后的善走效果。
- 原创候选：低姿态觅食，站立察看；受到追逐时躲入植被，保持距离时逐渐靠近。
- 玩家行动：观察、投放食物、寻找栖息地，或狩猎。
- 回报候选：行为记录、路线线索、移动类材料或食物。
- 待讨论：与玩家建立关系后，带路、寻找资源还是成为伙伴？“速度”作为食用效果与生物自身能力应分开设计。

### 九尾狐：声音与危险

- 原著：《南山经》青丘之山，九尾、叫声似婴儿，能够食人；正文另记食用后的不蛊效果。
- 原创候选：密林中的叫声、尾影、巢穴警戒；决定是否增加诱导、幻象和绕行伏击。
- 玩家行动：辨别声源、观察领地、准备反制工具，或尝试特殊互动。
- 回报候选：狐类材料、抗干扰装备、领地情报。
- 待讨论：主要是野生掠食者、能够交流的灵兽，还是不同个体有不同倾向？幻术、化人和魅惑需要另标来源，不能直接说成这段正文的记载。

### 毕方：火灾与灾兆

- 原著：《西山经》章莪之山，鹤形、独足、青色底与红色纹理、白喙；出现在火灾征兆的语境中。
- 正文没有直接说明它会喷火，也没有在这段明确建立它主动纵火的因果。
- 原创方案 A：预兆者。提前出现，玩家通过声音与环境变化预判局部火灾事件。
- 原创方案 B：与火共生。趋近热源，在余烬中活动；是否造成新火灾另行设定。
- 原创方案 C：火焰战斗异兽。明确标为改编，设计可辨认的蓄势与攻击范围。
- 待讨论：它带来的主要体验是敬畏、灾害应对还是战斗？事件如何避免反复破坏玩家建筑？

### 精卫：有目的的行动

- 原著：《北山经》发鸠之山，鸟形、花纹头部、白喙、红足，具有衔西山木石填东海的行为与女娃身世。
- 原创候选：在已加载区域内取小型木石物品，沿可见路线飞往预设投放点。
- 玩家行动：观察路线、提供木石、帮助完成一段局部事件。
- 回报候选：记录、纪念物、事件进展；是否给予实用能力仍待讨论。
- 待讨论：保留独立使命还是允许建立伙伴关系？若改动实际水域或方块，需要明确范围与玩家授权机制。

## 装备与物品候选

| 候选 | 依据与性质 | 解决的玩家问题 | 限制或代价候选 |
| --- | --- | --- | --- |
| 迷榖路标／佩饰 | 《南山经》记迷榖佩戴可避免迷路；具体工具为原创 | 探索后寻找自己标记的归路 | 必须先设置锚点；只能指向已记录地点 |
| 祝余行粮 | 《南山经》记祝余食后不饥；具体数值为改编 | 支持远行与观察 | 有时限、产地限制或加工需求 |
| 丹木御火食物／护具 | 《西山经》记丹木果实可御火；护具为原创 | 应对火灾或热区 | 消耗储量或耐久；保护类型需要区分火焰与岩浆 |
| 毕方相关火器 | 根据火灾关联原创 | 制造可控热源或范围攻击 | 充能、蓄势、过热与环境影响 |
| 玉制护符与祭器 | 原著多见玉与山神祭仪；具体效果为原创 | 特殊互动、领地通行或事件应对 | 对象、地点与材料条件 |
| 图鉴与观察工具 | 原创系统 | 将线索变成玩家能利用的知识 | 信息随实际观察逐步解锁 |

装备要有明确使用情境：准备、使用、回报和代价。
武器可考虑弓、矛、斧、法器等不同操作，但先确定要应对什么生物，再决定形式。
材料可以来自狩猎、采集、自然脱落、互动和事件；不同途径的速度、风险与收益应各有取舍。
不预先决定全部异兽都可驯服、全部装备都高于原版，或全部材料都由击杀获得。

## AI 的设计问题

先写玩家看得见的行为，再选择实现方式。
每种异兽需要回答：它感知什么、想要什么、害怕什么、记住什么，以及玩家如何改变它的选择。

候选结构：

- 感知：可见目标、附近声音、气味标记或资源、局部地形与环境。感知有距离和遮挡条件。
- 动机：饥饿、休息、避险、护巢、追猎、好奇、特定使命；不同种类有不同权重。
- 状态：觅食、休息、警戒、接近、追逐、攻击、撤退与恢复等，按物种选用。
- 记忆：短期目标和最后发现位置；领地、关系等需要保存的长期信息另行记录。
- 动作与反馈：转头、立耳、收尾、低鸣、蓄势、奔跑与攻击，向玩家展示状态变化。

九尾狐候选流程：游荡 → 察觉玩家 → 观察 → 选择绕行或退避 → 蓄势 → 扑击 → 恢复。
失去视线后去最后看见的位置搜索；持续找不到则结束追逐。
受伤、目标离开领地或反制条件出现，可以中断原流程。
幻象若采用，需要设计识别线索和脱离办法，避免只靠隐藏规则惩罚玩家。

战斗设计需要说明：攻击前兆、范围、躲避方式、恢复窗口与撤退条件。
生态设计需要说明：日常活动为何发生、路径失败如何恢复、附近没有目标时做什么。
关系设计需要说明：信任如何增减、个体是否记住伤害、喂食是否受冷却或次数限制。

实现候选：有限状态与行为优先级相结合，复用觅食、避险等通用行为，保留物种专属动作。
服务器管理行为结果，客户端表现动画与音效；具体 API 在版本锁定后选。
限制感知与寻路频率；远处简化行为；避免无限追踪、跨区块搜索和无上限方块改动。

## 尚需构筑的世界内容

- 栖息地如何对应原版地形，或增加局部山域、遗迹与特殊植物群落。
- 异兽出现需要哪些可理解的条件，线索能否帮助玩家找到稀有目标。
- 图鉴是见到即解锁，还是通过观察行为、采集样本逐步完善。
- 原著的食用、佩戴、御凶等效果如何转译成游戏机制与材料用途。
- 山神与祭仪是背景、事件，还是可互动系统；避免提前绑定唯一发展路线。
- 装备、植物、营地和建筑是否让偏好非战斗的玩家也有目标。

## 下一轮讨论的入口

先选一个代表性场景，共同设计玩家从看见线索到结束遭遇的全过程。
候选：招摇山的第一次考察、青丘夜间寻声、毕方出没的火灾预兆、海岸边帮助精卫。
随后用同一套问题扩展其他内容，再选第一批实现目标。
