# 山海经 Minecraft 模组

以《山海经》为灵感的 Minecraft 模组项目，目前处于世界观与玩法构思阶段。

设计围绕「场景 → 生物 → 禁忌 → 物品」展开，将神话生物的生态、稀有存在的规则与玩家探索体验联系起来。
